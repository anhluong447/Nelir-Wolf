Nạp toàn bộ cơ sở dữ liệu dịch thuật từ file gói .nel (Nelir Project File).
Nếu bạn chia sẻ file .nel sang máy khác, hãy dán đường dẫn thư mục game trên máy mới này để có thể bấm nút Patch vào Game ngay lập tức.
